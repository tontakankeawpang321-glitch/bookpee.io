อีบุ๊กจาก Project Gutenberg เรื่อง สุนทรพจน์ในพิธีสาบานตนรับตำแหน่งประธานาธิบดีสมัยที่สองของเอบราฮัม ลินคอล์น

อีบุ๊กเล่มนี้จัดทำขึ้นเพื่อให้ทุกคนในสหรัฐอเมริกาและพื้นที่ส่วนใหญ่ทั่วโลกได้ใช้งานโดยไม่มีค่าใช้จ่ายและแทบไม่มีข้อจำกัดใดๆ คุณสามารถคัดลอก ส่งต่อ หรือนำกลับมาใช้ใหม่ได้ภายใต้เงื่อนไขของใบอนุญาต Project Gutenberg ที่มาพร้อมกับอีบุ๊กเล่มนี้ หรือเข้าชมทางออนไลน์ได้ที่ www.gutenberg.org หากคุณไม่ได้พำนักอยู่ในสหรัฐอเมริกา โปรดตรวจสอบกฎหมายของประเทศที่คุณพำนักอยู่ก่อนใช้งานอีบุ๊กเล่มนี้

ข้อความอิเล็กทรอนิกส์ดั้งเดิมทั้งหมดของ Project Gutenberg ในช่วงทศวรรษ 1970 ถูกจัดทำขึ้นด้วยตัวพิมพ์ใหญ่ทั้งหมด โดยไม่มีตัวพิมพ์เล็ก เนื่องจากคอมพิวเตอร์ที่เราใช้ในสมัยนั้นไม่มีฟังก์ชันตัวพิมพ์เล็กเลย

สุนทรพจน์ในพิธีสาบานตนรับตำแหน่งประธานาธิบดีสมัยที่สองของลินคอล์น

4 มีนาคม ค.ศ. 1865

เพื่อนร่วมชาติทั้งหลาย: ในวาระที่ข้าพเจ้ามาปรากฏตัวต่อหน้าท่านเป็นครั้งที่สองเพื่อกล่าวคำสาบานตนรับตำแหน่งประธานาธิบดีนี้ มีเหตุจำเป็นที่จะต้องกล่าวสุนทรพจน์อันยืดยาวน้อยกว่าเมื่อครั้งแรกมากนัก ในตอนนั้น การแถลงรายละเอียดเกี่ยวกับแนวทางที่ตั้งใจจะดำเนินไปดูจะเป็นสิ่งที่เหมาะสมและควรแก่กาล แต่ในขณะนี้ เมื่อเวลาล่วงเลยมาครบสี่ปี ซึ่งตลอดช่วงเวลานั้นได้มีการประกาศแถลงการณ์ต่อสาธารณะอย่างต่อเนื่องในทุกประเด็นและทุกแง่มุมของการต่อสู้ครั้งสำคัญที่ยังคงดึงดูดความสนใจและพลังกายพลังใจของคนในชาติอยู่ จึงไม่มีเรื่องราวใหม่ๆ ให้ต้องกล่าวถึงมากนัก ความก้าวหน้าของการสู้รบซึ่งเป็นปัจจัยหลักที่ทุกสิ่งขึ้นอยู่นั้น เป็นที่ประจักษ์ต่อสาธารณชนดีอยู่แล้วไม่ต่างจากข้าพเจ้า และข้าพเจ้าเชื่อว่าผลที่ออกมาเป็นที่น่าพอใจและเป็นกำลังใจให้แก่พวกเราทุกคนอย่างสมเหตุสมผล แม้ข้าพเจ้าจะเปี่ยมไปด้วยความหวังอันยิ่งใหญ่ต่ออนาคต แต่ข้าพเจ้าก็ไม่ขอบังอาจคาดการณ์สิ่งใดในเรื่องนี้

ในวาระที่ตรงกับเมื่อสี่ปีที่แล้ว ความคิดคำนึงของทุกคนต่างมุ่งตรงไปยังสงครามกลางเมืองที่กำลังจะปะทุขึ้นด้วยความวิตกกังวล ทุกคนหวาดกลัวมัน—ทุกคนต่างพยายามหลีกเลี่ยงมัน ในขณะที่สุนทรพจน์วันเข้ารับตำแหน่งกำลังถูกกล่าวขึ้น ณ สถานที่แห่งนี้ เพื่ออุทิศให้กับการรักษาความเป็นสหภาพไว้โดยไม่ใช้กำลังทหาร แต่กลุ่มผู้ก่อความไม่สงบกลับอยู่ในเมืองเพื่อมุ่งทำลายมันโดยไม่ต้องทำสงคราม—มุ่งหวังที่จะยุบสหภาพและแบ่งแยกผลประโยชน์ผ่านการเจรจา ทั้งสองฝ่ายต่างประณามสงคราม แต่ฝ่ายหนึ่งกลับเลือกที่จะทำสงครามดีกว่ายอมให้ชาติอยู่รอด และอีกฝ่ายหนึ่งก็ยอมรับสงครามดีกว่ายอมให้ชาติล่มสลาย และสงครามก็เกิดขึ้นในที่สุด

ประชากรหนึ่งในแปดของทั้งหมดเป็นทาสผิวดำ ซึ่งไม่ได้กระจายอยู่ทั่วไปในสหภาพ แต่กระจุกตัวอยู่ในพื้นที่ทางตอนใต้ ทาสเหล่านี้เป็นกลุ่มผลประโยชน์ที่แปลกแยกและทรงพลัง ทุกคนต่างรู้ดีว่ากลุ่มผลประโยชน์นี้เองที่เป็นต้นเหตุของสงครามอย่างมิต้องสงสัย เป้าหมายที่กลุ่มผู้ก่อความไม่สงบยอมกัดกร่อนทำลายสหภาพ แม้ต้องแลกด้วยสงคราม คือการเสริมสร้างความเข้มแข็ง รักษาให้คงอยู่ และขยายขอบเขตผลประโยชน์นี้ออกไป ในขณะที่ฝ่ายรัฐบาลยืนกรานว่าไม่มีสิทธิอื่นใดมากไปกว่าการจำกัดพื้นที่ขยายตัวของทาสเหล่านั้น

ไม่มีฝ่ายใดคาดคิดว่าสงครามจะขยายวงกว้างหรือยืดเยื้อนานดังที่เป็นอยู่เช่นนี้ ไม่มีใครคาดการณ์ว่าต้นเหตุของความขัดแย้งอาจยุติลงพร้อมกับ หรือแม้แต่ก่อนที่ความขัดแย้งจะยุติด้วยซ้ำ ต่างฝ่ายต่างหวังจะได้รับชัยชนะโดยง่าย และคาดหวังผลลัพธ์ที่รุนแรงน้อยกว่าและไม่น่าตระหนกเท่าที่ควร ทั้งสองฝ่ายต่างอ่านพระคัมภีร์ไบเบิลเล่มเดียวกัน และสวดอ้อนวอนต่อพระผู้เป็นเจ้าองค์เดียวกัน ต่างฝ่ายต่างอ้อนวอนขอการช่วยเหลือจากพระองค์เพื่อต่อต้านอีกฝ่าย มันอาจดูแปลกประหลาดที่มนุษย์ผู้ใดจะกล้าขอความช่วยเหลือจากพระผู้เป็นเจ้าผู้ทรงความยุติธรรม ในการรีดเค้นหาเลี้ยงชีพจากหยาดเหงื่อบนใบหน้าของผู้อื่น แต่ขอให้เราอย่าได้ตัดสินใคร เพื่อที่เราจะได้ไม่ถูกตัดสินเช่นกัน คำอ้อนวอนของทั้งสองฝ่ายไม่สามารถได้รับคำตอบพร้อมกันได้—และคำอ้อนวอนของฝ่ายใดก็ยังไม่ได้รับคำตอบอย่างเต็มที่นัก

พระผู้ทรงมหิทธิฤทธิ์ทรงมีพระประสงค์ของพระองค์เอง “วิบัติจงมีแก่โลกเพราะเหตุแห่งการล่วงละเมิด! ด้วยว่าการล่วงละเมิดนั้นจำเป็นต้องมีมา แต่ความวิบัตินั้นย่อมตกแก่ผู้ที่ก่อให้เกิดการล่วงละเมิดนั้น” หากเราพึงสันนิษฐานได้ว่า ระบอบทาสในอเมริกาคือหนึ่งในการล่วงละเมิดเหล่านั้น ซึ่งตามเทวลิขิตของพระเจ้าจำเป็นต้องเกิดขึ้น แต่เมื่อเวลาอันควรที่พระองค์ทรงกำหนดไว้สิ้นสุดลง พระองค์ทรงประสงค์ที่จะขจัดมันออกไป และทรงบันดาลให้เกิดสงครามอันน่าสยดสยองนี้แก่ทั้งฝ่ายเหนือและฝ่ายใต้ เพื่อเป็นความวิบัติอันสาสมต่อผู้ที่ก่อให้เกิดการล่วงละเมิดนั้น เราจะยังมองเห็นร่องรอยของการเบี่ยงเบนไปจากคุณลักษณะแห่งพระผู้เป็นเจ้าที่เหล่าผู้ศรัทธาในพระเจ้าผู้ทรงพระชนม์อยู่มอบแด่พระองค์เสมอมาหรือไม่? เราต่างตั้งความหวังอย่างเปี่ยมล้น และร่วมสวดอ้อนวอนอย่างแรงกล้า ขอให้มหันตภัยแห่งสงครามนี้ผ่านพ้นไปโดยเร็ว อย่างไรก็ตาม หากพระเจ้าทรงปรารถนาให้สงครามดำเนินต่อไป จนกว่าทรัพย์สินทั้งมวลที่พูนขึ้นจากการตรากตรำอย่างไม่ได้รับค่าตอบแทนตลอดสองร้อยห้าสิบปีของเหล่าทาสจะมลายสิ้นไป และจนกว่าเลือดทุกหยาดที่หลั่งรินจากรอยแส้จะถูกชดใช้ด้วยเลือดที่หลั่งชโลมด้วยคมดาบ ดังที่เคยกล่าวไว้เมื่อสามพันปีก่อนฉันใด บัดนี้ก็ยังต้องกล่าวอยู่ฉันนั้นว่า “การพิพากษาขององค์พระผู้เป็นเจ้านั้นเที่ยงธรรมและชอบธรรมสิ้นดี”

ปราศจากความอาฆาตมาดร้ายต่อผู้ใด เปี่ยมด้วยเมตตาธรรมต่อคนทุกผู้ ยืนหยัดในสิ่งที่ถูกต้องตามแต่ที่พระเจ้าจะทรงประทานให้เราเห็นว่าสิ่งนั้นถูกต้อง ขอให้เรามุ่งมั่นฟันฝ่าเพื่อบรรลุภารกิจที่เรากำลังทำอยู่นี้ให้ลุล่วง เพื่อสมานบาดแผลของชาติ เพื่อดูแลผู้ที่ได้ผ่านศึกสงคราม ตลอดจนเหล่าหญิงม่ายและเด็กกำพร้าของพวกเขา เพื่อทำทุกวิถีทางที่จะนำมาซึ่งสันติภาพอันเที่ยงธรรมและยั่งยืนในหมู่พวกเราเองและกับนานาประเทศ

*** จบฉบับอิเล็กทรอนิกส์ของโปรเจกต์กูเทนแบร์ก: คำปราศรัยเข้ารับตำแหน่งประธานาธิบดีครั้งที่สองของเอบราแฮม ลินคอล์น ***
ฉบับปรับปรุงใหม่จะเข้าแทนที่ฉบับเดิม—โดยฉบับเก่าจะถูกเปลี่ยนชื่อ
การสร้างสรรค์ผลงานจากสิ่งพิมพ์ที่ไม่อยู่ภายใต้การคุ้มครองของกฎหมายลิขสิทธิ์ของสหรัฐอเมริกา หมายความว่าไม่มีผู้ใดเป็นเจ้าของลิขสิทธิ์ในผลงานเหล่านี้ในสหรัฐอเมริกา ดังนั้นมูลนิธิ (และคุณด้วย!) จึงสามารถคัดลอกและเผยแพร่ผลงานนี้ในสหรัฐอเมริกาได้โดยไม่ต้องขออนุญาตและไม่ต้องจ่ายค่าลิขสิทธิ์ กฎเกณฑ์พิเศษที่ระบุไว้ในส่วนข้อกำหนดการใช้งานทั่วไปของสัญญาอนุญาตนี้ จะนำมาใช้กับการคัดลอกและการเผยแพร่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg™ เพื่อปกป้องแนวคิดและเครื่องหมายการค้า PROJECT GUTENBERG™ ทั้งนี้ Project Gutenberg เป็นเครื่องหมายการค้าจดทะเบียน และห้ามนำไปใช้หากคุณมีการเรียกเก็บเงินสำหรับอีบุ๊ก เว้นแต่จะเป็นไปตามข้อกำหนดของสัญญาอนุญาตเครื่องหมายการค้า ซึ่งรวมถึงการจ่ายค่าสิทธิเพื่อใช้เครื่องหมายการค้า Project Gutenberg หากคุณไม่เรียกเก็บค่าใช้จ่ายใดๆ ในการแจกจ่ายอีบุ๊กเล่มนี้ การปฏิบัติตามสัญญาอนุญาตเครื่องหมายการค้าจะเป็นเรื่องที่ง่ายมาก คุณอาจใช้อีบุ๊กนี้เพื่อวัตถุประสงค์เกือบทุกอย่าง เช่น การสร้างงานต่อเนื่อง รายงาน การแสดง และงานวิจัย อีบุ๊กของ Project Gutenberg อาจได้รับการดัดแปลง พิมพ์ และแจกจ่าย—คุณสามารถทำแทบจะ ทุกอย่าง ในสหรัฐอเมริกาด้วยอีบุ๊กที่ไม่อยู่ภายใต้การคุ้มครองของกฎหมายลิขสิทธิ์ของสหรัฐอเมริกา การเผยแพร่ซ้ำจะต้องเป็นไปตามสัญญาอนุญาตเครื่องหมายการค้า โดยเฉพาะอย่างยิ่งการเผยแพร่ซ้ำเพื่อการค้า

เพื่อปกป้องพันธกิจของ Project Gutenberg™ ในการส่งเสริมการเผยแพร่ผลงานอิเล็กทรอนิกส์โดยเสรี การที่คุณใช้งานหรือเผยแพร่ผลงานชิ้นนี้ (หรือผลงานอื่นใดที่เกี่ยวข้องกับคำว่า “Project Gutenberg”) ถือว่าคุณตกลงที่จะปฏิบัติตามข้อกำหนดทั้งหมดของสัญญาอนุญาต Project Gutenberg ฉบับเต็ม ซึ่งมีอยู่ในไฟล์นี้หรือทางออนไลน์ที่ www.gutenberg.org/license
ส่วนที่ 1. ข้อกำหนดทั่วไปในการใช้งานและการเผยแพร่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg
1.A. ในการอ่านหรือใช้งานส่วนใดก็ตามของผลงานอิเล็กทรอนิกส์ของ Project Gutenberg ชิ้นนี้ ถือว่าคุณได้แสดงเจตจำนงว่าคุณได้อ่าน ทำความเข้าใจ ตกลง และยอมรับข้อกำหนดทั้งหมดของสัญญาอนุญาตนี้ รวมถึงข้อตกลงด้านทรัพย์สินทางปัญญา (เครื่องหมายการค้า/ลิขสิทธิ์) แล้ว หากคุณไม่ตกลงที่จะปฏิบัติตามข้อกำหนดทั้งหมดของข้อตกลงนี้ คุณต้องยุติการใช้งาน และส่งคืนหรือทำลายสำเนาของผลงานอิเล็กทรอนิกส์ของ Project Gutenberg ทั้งหมดที่อยู่ในความครอบครองของคุณ หากคุณได้ชำระค่าธรรมเนียมเพื่อให้ได้สำเนาหรือการเข้าถึงผลงานอิเล็กทรอนิกส์ของ Project Gutenberg และคุณไม่ตกลงที่จะผูกพันตามข้อกำหนดของข้อตกลงนี้ คุณอาจขอรับเงินคืนจากบุคคลหรือนิติบุคคลที่คุณได้ชำระเงินให้ตามที่ระบุไว้ในย่อหน้า 1.E.8.
1.B. “Project Gutenberg” เป็นเครื่องหมายการค้าจดทะเบียน ซึ่งจะใช้กับหรือเกี่ยวข้องกับผลงานอิเล็กทรอนิกส์ได้เฉพาะโดยบุคคลที่ตกลงจะผูกพันตามข้อกำหนดของข้อตกลงนี้เท่านั้น มีบางสิ่งที่คุณสามารถทำได้กับผลงานอิเล็กทรอนิกส์ส่วนใหญ่ของ Project Gutenberg แม้ว่าจะไม่ได้ปฏิบัติตามข้อกำหนดฉบับเต็มของข้อตกลงนี้ก็ตาม (ดูรายละเอียดในย่อหน้า 1.C. ด้านล่าง) และยังมีอีกหลายสิ่งที่คุณสามารถทำได้กับผลงานอิเล็กทรอนิกส์ของ Project Gutenberg หากคุณปฏิบัติตามข้อกำหนดของข้อตกลงนี้และช่วยรักษาการเข้าถึงผลงานอิเล็กทรอนิกส์ของ Project Gutenberg โดยเสรีในอนาคต (ดูรายละเอียดในย่อหน้า 1.E. ด้านล่าง)
1.C. มูลนิธิคลังวรรณกรรม Project Gutenberg (Project Gutenberg Literary Archive Foundation หรือ “มูลนิธิ” หรือ PGLAF) เป็นเจ้าของลิขสิทธิ์ในการรวบรวม (compilation copyright) ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg ทั้งนี้ ผลงานแต่ละชิ้นในคอลเลกชันเกือบทั้งหมดเป็นสาธารณสมบัติในสหรัฐอเมริกา หากผลงานชิ้นใดไม่ได้รับความคุ้มครองภายใต้กฎหมายลิขสิทธิ์ในสหรัฐอเมริกาและคุณอาศัยอยู่ในสหรัฐอเมริกา เราไม่อ้างสิทธิ์ในการขัดขวางไม่ให้คุณคัดลอก แจกจ่าย แสดงผล จัดแสดง หรือสร้างงานดัดแปลงโดยอ้างอิงจากผลงานนั้น ตราบเท่าที่การอ้างอิงถึง Project Gutenberg ทั้งหมดถูกลบออก แน่นอนว่าเราหวังว่าคุณจะสนับสนุนพันธกิจของ Project Gutenberg ในการส่งเสริมการเข้าถึงผลงานอิเล็กทรอนิกส์โดยเสรี ด้วยการแบ่งปันผลงานของ Project Gutenberg อย่างเสรีเพื่อให้เป็นไปตามข้อกำหนดของข้อตกลงนี้เพื่อรักษาชื่อของ Project Gutenberg ให้คงอยู่คู่กับผลงาน คุณสามารถปฏิบัติตามข้อกำหนดของข้อตกลงนี้ได้อย่างง่ายดายโดยการคงผลงานชิ้นนี้ไว้ในรูปแบบเดิมพร้อมกับสัญญาอนุญาตฉบับเต็มของ Project Gutenberg เมื่อคุณแบ่งปันผลงานให้ผู้อื่นโดยไม่มีการเรียกเก็บค่าใช้จ่าย
1.D. กฎหมายลิขสิทธิ์ในสถานที่ที่คุณพำนักอยู่มีผลบังคับต่อสิ่งที่คุณสามารถทำได้กับผลงานชิ้นนี้ด้วย กฎหมายลิขสิทธิ์ในประเทศส่วนใหญ่อยู่ในสภาวะที่มีการเปลี่ยนแปลงอยู่เสมอ หากคุณอยู่นอกสหรัฐอเมริกา โปรดตรวจสอบกฎหมายของประเทศคุณเพิ่มเติมจากข้อกำหนดของข้อตกลงนี้ก่อนที่จะดาวน์โหลด คัดลอก จัดแสดง แสดงผล แจกจ่าย หรือสร้างงานดัดแปลงตามผลงานชิ้นนี้ หรือผลงานอื่นใดของ Project Gutenberg มูลนิธิไม่ขอรับรองสถานะลิขสิทธิ์ของผลงานใดๆ ในประเทศอื่นใดนอกเหนือจากสหรัฐอเมริกา
1.E. เว้นแต่คุณได้ลบการอ้างอิงถึง Project Gutenberg ออกทั้งหมด:
1.E.1. ประโยคต่อไปนี้ พร้อมลิงก์ที่ใช้งานได้หรือช่องทางอื่นที่เข้าถึงข้อกำหนดฉบับเต็มของใบอนุญาต Project Gutenberg ได้ทันที จะต้องปรากฏให้เห็นอย่างชัดเจนทุกครั้งที่มีการเข้าถึง แสดงผล นำเสนอ รับชม คัดลอก หรือเผยแพร่ผลงานใดๆ ของ Project Gutenberg (ซึ่งหมายถึงผลงานใดก็ตามที่มีชื่อ “Project Gutenberg” ปรากฏอยู่ หรือมีความเกี่ยวข้องกับชื่อ “Project Gutenberg”):
หนังสืออิเล็กทรอนิกส์เล่มนี้จัดทำขึ้นเพื่อให้ทุกคน ไม่ว่าจะอยู่ที่ใดในสหรัฐอเมริกาหรือพื้นที่ส่วนใหญ่ทั่วโลก สามารถใช้งานได้โดยไม่มีค่าใช้จ่ายและแทบไม่มีข้อจำกัดใดๆ ทั้งสิ้น คุณสามารถคัดลอก มอบให้ผู้อื่น หรือนำกลับมาใช้ใหม่ได้ภายใต้เงื่อนไขของใบอนุญาต Project Gutenberg™ ที่แนบมากับหนังสือเล่มนี้ หรือผ่านช่องทางออนไลน์ที่ www.gutenberg.org หากคุณไม่ได้พำนักอยู่ในสหรัฐอเมริกา โปรดตรวจสอบกฎหมายของประเทศที่คุณอยู่ก่อนเริ่มใช้งานหนังสือเล่มนี้
1.E.2. หากผลงานอิเล็กทรอนิกส์ของ Project Gutenberg ชิ้นใดชิ้นหนึ่ง พัฒนามาจากเนื้อหาที่ไม่ได้รับความคุ้มครองตามกฎหมายลิขสิทธิ์ของสหรัฐอเมริกา (ไม่มีข้อความระบุว่าเผยแพร่โดยได้รับอนุญาตจากเจ้าของลิขสิทธิ์) ผลงานนั้นสามารถคัดลอกและเผยแพร่แก่บุคคลใดก็ได้ในสหรัฐอเมริกาโดยไม่ต้องเสียค่าธรรมเนียมหรือค่าใช้จ่ายใดๆ ทั้งสิ้น แต่หากคุณนำผลงานที่มีชื่อ “Project Gutenberg” ปรากฏอยู่หรือเกี่ยวข้องด้วยไปเผยแพร่ต่อหรือเปิดให้ผู้อื่นเข้าถึง คุณต้องปฏิบัติตามข้อกำหนดในย่อหน้าที่ 1.E.1 ถึง 1.E.7 หรือมิฉะนั้นต้องได้รับอนุญาตให้ใช้ผลงานและเครื่องหมายการค้า Project Gutenberg ตามที่ระบุไว้ในย่อหน้าที่ 1.E.8 หรือ 1.E.9
1.E.3. ในกรณีที่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg เผยแพร่โดยได้รับอนุญาตจากเจ้าของลิขสิทธิ์ การใช้งานและการเผยแพร่ของคุณจะต้องปฏิบัติตามทั้งข้อกำหนดในย่อหน้าที่ 1.E.1 ถึง 1.E.7 และข้อกำหนดเพิ่มเติมอื่นๆ ที่เจ้าของลิขสิทธิ์ระบุไว้ โดยข้อกำหนดเพิ่มเติมเหล่านี้จะมีการเชื่อมโยงไว้กับใบอนุญาต Project Gutenberg สำหรับทุกผลงานที่ได้รับอนุญาตจากเจ้าของลิขสิทธิ์ ซึ่งระบุไว้ที่ส่วนต้นของผลงานชิ้นนี้
1.E.4. ห้ามตัดการเชื่อมโยง แยกส่วน หรือลบข้อกำหนดใบอนุญาตฉบับเต็มของ Project Gutenberg ออกจากผลงานนี้ รวมถึงห้ามกระทำเช่นนั้นกับไฟล์ใดๆ ที่มีส่วนประกอบของผลงานนี้ หรือผลงานอื่นใดที่เกี่ยวข้องกับ Project Gutenberg
1.E.5. ห้ามคัดลอก แสดงผล นำเสนอ แจกจ่าย หรือเผยแพร่ผลงานอิเล็กทรอนิกส์นี้ หรือส่วนใดส่วนหนึ่งของผลงาน โดยไม่แสดงประโยคที่กำหนดไว้ในย่อหน้าที่ 1.E.1 อย่างชัดเจน พร้อมลิงก์ที่ใช้งานได้หรือช่องทางที่สามารถเข้าถึงข้อกำหนดฉบับเต็มของใบอนุญาต Project Gutenberg ได้ทันที
1.E.6. คุณสามารถดัดแปลงและเผยแพร่ผลงานนี้ในรูปแบบไฟล์ไบนารี ไฟล์บีบอัด ไฟล์มาร์กอัป รวมถึงรูปแบบที่มีลิขสิทธิ์เฉพาะหรือรูปแบบทั่วไป ตลอดจนรูปแบบโปรแกรมประมวลผลคำหรือไฮเปอร์เท็กซ์ใดๆ อย่างไรก็ตาม หากคุณเปิดให้เข้าถึงหรือเผยแพร่สำเนาผลงานของ Project Gutenberg ในรูปแบบอื่นนอกเหนือจาก “Plain Vanilla ASCII” หรือรูปแบบที่ใช้ในเวอร์ชันทางการบนเว็บไซต์ Project Gutenberg (www.gutenberg.org) คุณต้องจัดหาสำเนา วิธีการส่งออกสำเนา หรือวิธีการขอรับสำเนาในรูปแบบ “Plain Vanilla ASCII” ดั้งเดิมหรือรูปแบบทางการอื่นๆ ให้แก่ผู้ใช้ตามคำขอ โดยไม่มีค่าใช้จ่ายหรือค่าธรรมเนียมเพิ่มเติม ทั้งนี้ รูปแบบไฟล์อื่นๆ ทั้งหมดจะต้องรวมข้อกำหนดใบอนุญาตฉบับเต็มของ Project Gutenberg ตามที่ระบุในย่อหน้าที่ 1.E.1 ไว้ด้วย
1.E.7. ห้ามเรียกเก็บค่าธรรมเนียมในการเข้าถึง รับชม แสดงผล นำเสนอ คัดลอก หรือเผยแพร่ผลงานใดๆ ของ Project Gutenberg เว้นแต่คุณจะปฏิบัติตามข้อกำหนดในย่อหน้าที่ 1.E.8 หรือ 1.E.9
1.E.8. คุณอาจเรียกเก็บค่าธรรมเนียมที่เหมาะสมสำหรับการมอบสำเนา การเปิดให้เข้าถึง หรือการเผยแพร่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg ได้ โดยมีเงื่อนไขดังนี้:
  • • คุณต้องชำระค่าลิขสิทธิ์ในอัตราร้อยละ 20 ของกำไรขั้นต้นที่ได้รับจากการใช้ผลงานของ Project Gutenberg โดยคำนวณตามวิธีการเดียวกับที่คุณใช้คำนวณภาษี ค่าธรรมเนียมนี้ถือเป็นหนี้ค้างชำระต่อเจ้าของเครื่องหมายการค้า Project Gutenberg แต่เจ้าของได้ตกลงที่จะบริจาคค่าลิขสิทธิ์ภายใต้ข้อกำหนดนี้ให้แก่ Project Gutenberg Literary Archive Foundation โดยต้องชำระค่าลิขสิทธิ์ภายใน 60 วันหลังจากวันที่คุณจัดทำ (หรือกฎหมายกำหนดให้จัดทำ) การยื่นแบบแสดงรายการภาษีตามรอบระยะเวลา ทั้งนี้ ควรระบุรายละเอียดการชำระค่าลิขสิทธิ์ให้ชัดเจนและส่งไปยัง Project Gutenberg Literary Archive Foundation ตามที่อยู่ที่ระบุไว้ในส่วนที่ 4 “ข้อมูลเกี่ยวกับการบริจาคให้แก่ Project Gutenberg Literary Archive Foundation”
  • • คุณต้องคืนเงินเต็มจำนวนให้แก่ผู้ใช้ที่แจ้งเป็นลายลักษณ์อักษร (หรือผ่านอีเมล) ภายใน 30 วันนับจากวันที่ได้รับผลงาน ว่าไม่ตกลงยอมรับเงื่อนไขของใบอนุญาต Project Gutenberg™ ฉบับเต็ม ในกรณีนี้ คุณต้องกำหนดให้ผู้ใช้รายดังกล่าวส่งคืนหรือทำลายสำเนาผลงานทั้งหมดที่อยู่ในรูปแบบสื่อทางกายภาพ และยุติการใช้งานรวมถึงการเข้าถึงสำเนาผลงานอื่นๆ ของ Project Gutenberg™ ทั้งหมด
  • • ในกรณีที่พบข้อบกพร่องในผลงานอิเล็กทรอนิกส์และมีการรายงานให้คุณทราบภายใน 90 วันนับจากวันที่ได้รับผลงาน คุณต้องคืนเงินเต็มจำนวนสำหรับผลงานชิ้นนั้นหรือจัดหาสำเนาชุดใหม่มาทดแทน ตามที่ระบุไว้ในย่อหน้าที่ 1.F.3
  • • คุณต้องปฏิบัติตามข้อกำหนดอื่นๆ ทั้งหมดในข้อตกลงนี้สำหรับการเผยแพร่ผลงานของ Project Gutenberg™ โดยไม่คิดค่าใช้จ่าย
1.E.9. หากคุณต้องการเรียกเก็บค่าธรรมเนียม หรือเผยแพร่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg™ ไม่ว่ารายชิ้นหรือเป็นกลุ่ม ภายใต้เงื่อนไขที่แตกต่างไปจากที่ระบุไว้ในข้อตกลงนี้ คุณต้องได้รับอนุญาตเป็นลายลักษณ์อักษรจาก Project Gutenberg Literary Archive Foundation ซึ่งเป็นผู้ดูแลเครื่องหมายการค้า Project Gutenberg™ โดยสามารถติดต่อมูลนิธิได้ตามรายละเอียดที่ระบุไว้ในส่วนที่ 3 ด้านล่าง
1.F.
1.F.1. เหล่าอาสาสมัครและพนักงานของ Project Gutenberg ทุ่มเทแรงกายแรงใจอย่างมากในการคัดเลือก ตรวจสอบลิขสิทธิ์ ถ่ายทอดเนื้อหา และพิสูจน์อักษรผลงานที่ไม่อยู่ภายใต้การคุ้มครองของกฎหมายลิขสิทธิ์ของสหรัฐอเมริกา เพื่อสร้างสรรค์คลังหนังสือของ Project Gutenberg™ ขึ้นมา อย่างไรก็ตาม แม้จะมีความพยายามดังกล่าว แต่ผลงานในรูปแบบอิเล็กทรอนิกส์ของ Project Gutenberg™ รวมถึงสื่อที่ใช้จัดเก็บ อาจมี "ข้อบกพร่อง" เช่น ข้อมูลไม่ครบถ้วน ไม่ถูกต้อง หรือเสียหาย, ความผิดพลาดในการคัดลอก, การละเมิดลิขสิทธิ์หรือทรัพย์สินทางปัญญาอื่นๆ, แผ่นดิสก์หรือสื่อจัดเก็บข้อมูลชำรุดเสียหาย, ไวรัสคอมพิวเตอร์ หรือรหัสคอมพิวเตอร์ที่อาจสร้างความเสียหายหรืออุปกรณ์ของคุณไม่สามารถอ่านได้
1.F.2. การรับประกันแบบจำกัด, การปฏิเสธความรับผิดชอบต่อความเสียหาย - นอกเหนือจาก "สิทธิในการเปลี่ยนสินค้าหรือคืนเงิน" ที่ระบุไว้ในย่อหน้าที่ 1.F.3 แล้ว มูลนิธิ Project Gutenberg Literary Archive Foundation ในฐานะเจ้าของเครื่องหมายการค้า Project Gutenberg™ รวมถึงบุคคลอื่นใดที่เผยแพร่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg™ ภายใต้ข้อตกลงนี้ ขอปฏิเสธความรับผิดชอบทั้งหมดต่อความเสียหาย ค่าใช้จ่าย และค่าธรรมเนียมต่างๆ รวมถึงค่าทนายความที่คุณอาจได้รับ คุณยอมรับว่าคุณไม่มีสิทธิเรียกร้องค่าชดเชยใดๆ จากความประมาทเลินเล่อ การรับผิดโดยเคร่งครัด การละเมิดการรับประกัน หรือการผิดสัญญา ยกเว้นตามที่ระบุไว้ในย่อหน้าที่ 1.F.3 เท่านั้น คุณตกลงว่ามูลนิธิ เจ้าของเครื่องหมายการค้า และผู้เผยแพร่รายใดก็ตามภายใต้ข้อตกลงนี้ จะไม่รับผิดชอบต่อความเสียหายที่เกิดขึ้นจริง ความเสียหายโดยตรง ความเสียหายโดยอ้อม ความเสียหายสืบเนื่อง ความเสียหายเพื่อเป็นการลงโทษ หรือความเสียหายจากเหตุสุดวิสัย แม้ว่าคุณจะได้รับแจ้งถึงความเป็นไปได้ที่จะเกิดความเสียหายดังกล่าวแล้วก็ตาม
1.F.3. สิทธิในการเปลี่ยนสินค้าหรือคืนเงินแบบจำกัด - หากคุณพบข้อบกพร่องในผลงานอิเล็กทรอนิกส์นี้ภายใน 90 วันหลังจากที่ได้รับ คุณสามารถขอรับเงินคืน (หากมี) ตามจำนวนที่คุณจ่ายไปได้ โดยส่งคำชี้แจงเป็นลายลักษณ์อักษรไปยังบุคคลที่คุณได้รับผลงานมา หากคุณได้รับผลงานในรูปแบบสื่อบันทึกข้อมูล คุณต้องส่งสื่อนั้นกลับคืนพร้อมกับคำชี้แจงของคุณ ทั้งนี้บุคคลหรือองค์กรที่ส่งมอบผลงานที่มีข้อบกพร่องให้แก่คุณ อาจเลือกที่จะจัดส่งสำเนาชุดใหม่ให้แทนการคืนเงิน หากคุณได้รับผลงานผ่านระบบอิเล็กทรอนิกส์ ผู้ส่งมอบอาจเลือกที่จะให้โอกาสคุณดาวน์โหลดหรือรับผลงานนั้นอีกครั้งแทนการคืนเงิน หากสำเนาชุดที่สองยังมีข้อบกพร่องอีก คุณสามารถทำเรื่องขอคืนเงินเป็นลายลักษณ์อักษรได้โดยไม่ต้องมีการแก้ไขปัญหาเพิ่มเติม
1.F.4. นอกเหนือจากสิทธิในการเปลี่ยนสินค้าหรือคืนเงินแบบจำกัดที่ระบุไว้ในย่อหน้าที่ 1.F.3 แล้ว ผลงานนี้ถูกส่งมอบให้แก่คุณ "ตามสภาพที่เป็นอยู่" (AS-IS) โดยไม่มีการรับประกันอื่นใด ไม่ว่าจะโดยชัดแจ้งหรือโดยนัย รวมถึงแต่ไม่จำกัดเพียงการรับประกันความเหมาะสมในการจำหน่าย หรือความเหมาะสมต่อวัตถุประสงค์การใช้งานอย่างใดอย่างหนึ่ง
1.F.5. ในบางรัฐอาจไม่อนุญาตให้มีการปฏิเสธการรับประกันโดยนัยบางประการ หรือการยกเว้นหรือจำกัดความรับผิดต่อความเสียหายบางประเภท หากการปฏิเสธความรับผิดชอบหรือข้อจำกัดที่ระบุในข้อตกลงนี้ขัดต่อกฎหมายของรัฐที่มีผลบังคับใช้ ให้ตีความข้อตกลงนี้เพื่อให้มีการปฏิเสธความรับผิดหรือข้อจำกัดสูงสุดเท่าที่กฎหมายของรัฐนั้นจะอนุญาต หากข้อกำหนดใดในข้อตกลงนี้เป็นโมฆะหรือไม่สามารถบังคับใช้ได้ ให้ถือว่าข้อกำหนดส่วนที่เหลือนั้นยังมีผลบังคับใช้ต่อไป
1.F.6. การชดใช้ค่าเสียหาย - คุณตกลงที่จะชดใช้ค่าเสียหายและปกป้องมูลนิธิ เจ้าของเครื่องหมายการค้า ตัวแทนหรือพนักงานของมูลนิธิ ผู้ที่จัดทำสำเนาผลงานอิเล็กทรอนิกส์ของ Project Gutenberg™ ตามข้อตกลงนี้ รวมถึงอาสาสมัครทุกคนที่มีส่วนเกี่ยวข้องกับการผลิต การส่งเสริมการขาย และการเผยแพร่ผลงานอิเล็กทรอนิกส์ของ Project Gutenberg™ ให้พ้นจากความรับผิด ค่าใช้จ่าย และค่าธรรมเนียมต่างๆ รวมถึงค่าทนายความ ซึ่งเกิดขึ้นไม่ว่าโดยตรงหรือโดยอ้อมจากสิ่งที่คุณได้กระทำหรือเป็นเหตุให้เกิดขึ้น ดังต่อไปนี้: (ก) การเผยแพร่ผลงานนี้หรือผลงานใดๆ ของ Project Gutenberg (ข) การปรับเปลี่ยน แก้ไข เพิ่มเติม หรือลบเนื้อหาในผลงานใดๆ ของ Project Gutenberg และ (ค) ข้อบกพร่องใดๆ ที่คุณเป็นผู้ก่อขึ้น
ส่วนที่ 2. ข้อมูลเกี่ยวกับพันธกิจของ Project Gutenberg
Project Gutenberg คือสัญลักษณ์ของการเผยแพร่ผลงานอิเล็กทรอนิกส์โดยไม่คิดมูลค่า ในรูปแบบที่สามารถอ่านได้ด้วยคอมพิวเตอร์ที่หลากหลายที่สุด ตั้งแต่คอมพิวเตอร์รุ่นเก่าที่ล้าสมัยไปจนถึงรุ่นใหม่ล่าสุด โครงการนี้ดำรงอยู่ได้ด้วยความพยายามของอาสาสมัครนับร้อยชีวิต และเงินบริจาคจากผู้คนในทุกสาขาอาชีพ
เหล่าอาสาสมัครและการสนับสนุนทางการเงินเพื่อให้พวกเขามีเครื่องมือที่จำเป็น คือหัวใจสำคัญในการบรรลุเป้าหมายของ Project Gutenberg และเพื่อให้มั่นใจว่าคลังหนังสือของโครงการนี้จะยังคงเปิดให้ใช้งานฟรีสำหรับคนรุ่นต่อๆ ไป ในปี ค.ศ. 2001 มูลนิธิ Project Gutenberg Literary Archive Foundation จึงได้ถูกก่อตั้งขึ้นเพื่อสร้างอนาคตที่มั่นคงและถาวรให้แก่ Project Gutenberg และคนรุ่นหลัง หากต้องการทราบข้อมูลเพิ่มเติมเกี่ยวกับมูลนิธิและวิธีที่คุณจะสามารถช่วยเหลือผ่านแรงกายหรือเงินบริจาคได้ โปรดดูในส่วนที่ 3 และ 4 รวมถึงหน้าข้อมูลของมูลนิธิที่ www.gutenberg.org
ส่วนที่ 3. ข้อมูลเกี่ยวกับมูลนิธิ Project Gutenberg Literary Archive Foundation
มูลนิธิ Project Gutenberg Literary Archive Foundation เป็นองค์กรทางการศึกษาที่ไม่แสวงหาผลกำไรตามมาตรา 501(c)(3) จัดตั้งขึ้นภายใต้กฎหมายของรัฐมิสซิสซิปปี และได้รับสถานะยกเว้นภาษีจากกรมสรรพากร (Internal Revenue Service) หมายเลขประจำตัวผู้เสียภาษี (EIN) ของมูลนิธิคือ 64-6221541 เงินบริจาคให้แก่ทางมูลนิธิสามารถนำไปลดหย่อนภาษีได้ตามที่กฎหมายของรัฐบาลกลางสหรัฐฯ และกฎหมายของรัฐที่คุณพำนักอยู่อนุญาต
สำนักงานของมูลนิธิตั้งอยู่ที่ 41 Watchung Plaza #516, Montclair NJ 07042, USA, โทร +1 (862) 621-9288 คุณสามารถดูช่องทางการติดต่อผ่านอีเมลและข้อมูลการติดต่อที่เป็นปัจจุบันได้ที่เว็บไซต์และหน้าเว็บหลักของมูลนิธิที่ www.gutenberg.org/contact
ส่วนที่ 4. ข้อมูลเกี่ยวกับการบริจาคเงินให้แก่โครงการมูลนิธิ Project Gutenberg Literary Archive Foundation
Project Gutenberg™ ต้องพึ่งพาและไม่สามารถอยู่รอดได้หากขาดการสนับสนุนและการบริจาคจากสาธารณชนในวงกว้าง เพื่อดำเนินพันธกิจในการเพิ่มจำนวนผลงานที่เป็นสาธารณสมบัติและผลงานที่ได้รับอนุญาต ซึ่งสามารถเผยแพร่ได้ฟรีในรูปแบบที่เครื่องจักรสามารถอ่านได้และเข้าถึงได้ด้วยอุปกรณ์ที่หลากหลายที่สุด แม้จะเป็นอุปกรณ์ที่ล้าสมัยแล้วก็ตาม เงินบริจาคจำนวนเล็กน้อย (ตั้งแต่ 1 ถึง 5,000 ดอลลาร์สหรัฐ) มีความสำคัญอย่างยิ่งต่อการรักษาสถานะยกเว้นภาษีจากกรมสรรพากร
มูลนิธิมีความมุ่งมั่นที่จะปฏิบัติตามกฎหมายที่ควบคุมองค์กรการกุศลและการบริจาคเพื่อการกุศลในทั้ง 50 รัฐของสหรัฐอเมริกา เนื่องจากข้อกำหนดในการปฏิบัติตามกฎหมายในแต่ละรัฐนั้นไม่เหมือนกัน จึงต้องใช้ความพยายามอย่างมาก ทั้งในเรื่องของเอกสารและค่าธรรมเนียมต่างๆ เพื่อให้สอดคล้องกับข้อกำหนดเหล่านี้ เราจะไม่ขอรับบริจาคในพื้นที่ที่เรายังไม่ได้รับการยืนยันการปฏิบัติตามกฎหมายเป็นลายลักษณ์อักษร หากต้องการส่งเงินบริจาคหรือตรวจสอบสถานะการปฏิบัติตามกฎหมายในแต่ละรัฐ โปรดไปที่ www.gutenberg.org/donate
แม้ว่าเราจะไม่สามารถและไม่ได้ขอรับบริจาคจากรัฐที่ยังไม่เป็นไปตามข้อกำหนดการรับบริจาคของเรา แต่เราก็ไม่มีข้อห้ามใดๆ ในการรับเงินบริจาคที่มีผู้ประสงค์จะมอบให้เองจากรัฐเหล่านั้น หากผู้บริจาคเป็นฝ่ายติดต่อเข้ามาเสนอความช่วยเหลือ
เรายินดีน้อมรับเงินบริจาคจากนานาชาติด้วยความขอบคุณอย่างยิ่ง อย่างไรก็ตาม เราไม่สามารถให้คำรับรองใดๆ เกี่ยวกับการลดหย่อนภาษีสำหรับเงินบริจาคที่ได้รับจากนอกสหรัฐอเมริกาได้ เนื่องจากลำพังเพียงกฎหมายของสหรัฐฯ เองก็มากเกินกว่าที่เจ้าหน้าที่จำนวนเพียงหยิบมือของเราจะรับมือไหวแล้ว
ท่านสามารถตรวจสอบวิธีการและที่อยู่สำหรับการรับบริจาคที่เป็นปัจจุบันได้ที่หน้าเว็บไซต์ของ Project Gutenberg เราเปิดรับบริจาคในหลากหลายรูปแบบ รวมถึงการใช้เช็ค การชำระเงินออนไลน์ และการบริจาคผ่านบัตรเครดิต หากท่านต้องการร่วมบริจาค โปรดไปที่: www.gutenberg.org/donate
ส่วนที่ 5. ข้อมูลทั่วไปเกี่ยวกับผลงานอิเล็กทรอนิกส์ของ Project Gutenberg
ศาสตราจารย์ Michael S. Hart คือผู้ริเริ่มแนวคิดของ Project Gutenberg ในการสร้างห้องสมุดผลงานอิเล็กทรอนิกส์ที่สามารถแบ่งปันให้แก่กันได้อย่างเสรี ท่านได้ทุ่มเทสร้างสรรค์และเผยแพร่ eBook ของ Project Gutenberg มายาวนานถึงสี่สิบปี โดยมีเพียงเครือข่ายอาสาสมัครที่ประสานงานกันอย่างอิสระคอยให้การสนับสนุน
eBook ของ Project Gutenberg มักถูกสร้างขึ้นจากการรวบรวมฉบับพิมพ์หลายฉบับเข้าด้วยกัน ซึ่งทั้งหมดได้รับการยืนยันแล้วว่าไม่ได้รับการคุ้มครองลิขสิทธิ์ในสหรัฐอเมริกา ยกเว้นในกรณีที่มีการระบุแจ้งลิขสิทธิ์ไว้ ดังนั้น eBook ของเราจึงไม่จำเป็นต้องมีเนื้อหาตรงตามต้นฉบับฉบับพิมพ์ที่เป็นกระดาษฉบับใดฉบับหนึ่งเสมอไป
คนส่วนใหญ่มักเริ่มต้นจากเว็บไซต์ของเราซึ่งมีเครื่องมือหลักสำหรับการค้นหาข้อมูลของ PG: www.gutenberg.org
ภายในเว็บไซต์นี้ประกอบไปด้วยข้อมูลเกี่ยวกับ Project Gutenberg รวมถึงวิธีการบริจาคเงินให้แก่ Project Gutenberg Literary Archive Foundation วิธีการช่วยเหลือในการสร้างสรรค์ eBook เล่มใหม่ๆ และวิธีสมัครรับจดหมายข่าวทางอีเมลเพื่อติดตามข่าวสารล่าสุดเกี่ยวกับ eBook ของเรา
